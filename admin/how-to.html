🐱 Primal Urge Admin — How To

A step-by-step guide for managing the Primal Urge website

Getting to the Admin Page

Open this address in your phone's browser:

https://www.core3.com/PrimalUrge/admin/

You will see a PIN entry screen. Enter your 4-digit PIN to unlock the admin tools.

Bookmark this page on your phone so you can get back to it quickly.

Editing Page Text (Rescue Description, Stats, Pricing)

At the top of the admin page you'll see a card called Page Content. This lets you update the text that appears in the Rescue section of the main website.

Rescue Description

The main paragraph about your history and experience. Edit the text in the big text box and tap Save Page Content.

Yearly Stat

The centered line that shows your annual spay/neuter count — for example: 2025 Spayed/Nuter 148. Update the number here each year.

Pricing Info

A single line for vaccine and spay/neuter pricing. Leave it blank if you don't want it shown on the page.

After saving, reload the main website page to see your changes live.

Adding a New Kitten

1Scroll past the Page Content card to the Add Kitten form.
2Tap Photo and choose a photo from your phone.
3Fill in Description / Name — e.g. Female Tuxedo, very playful.
4Choose Gender, enter the Adoption Fee, and confirm the Location.
5Set Status — Available Now shows the kitten right away. Coming Soon puts them in a separate section.
6Tap Save Kitten. The kitten appears on the main page immediately.

Editing an Existing Kitten

  1. Scroll down to the Current Kittens list.
  2. Find the kitten you want to change and tap Edit.
  3. The form at the top fills in with that kitten's current information.
  4. Make your changes. To replace the photo, tap Photo and choose a new image. Leave it empty to keep the current photo.
  5. Tap Save Kitten to apply the changes.
  6. Tap Cancel Edit if you change your mind.

Removing a Kitten

  1. Scroll to the Current Kittens list.
  2. Find the kitten and tap Delete.
  3. A confirmation message will appear — tap OK to confirm.
Deleting a kitten removes it from the website immediately and cannot be undone.

Turning the Donate Button On or Off

Each kitten card has a Donate button toggle switch. When it is on (green), a green Donate Now button appears on that kitten's card on the main website.

  • Slide the toggle right (green) to show the Donate button.
  • Slide it left (gray) to hide the Donate button.

Tips

  • All changes go live on the website the moment you save — no extra steps needed.
  • Photos are stored safely on the website's server.
  • If something doesn't look right after saving, try refreshing the main page.
  • If you get stuck, send the page link to your web person for help.
